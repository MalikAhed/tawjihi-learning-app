# Khotwa | Tawjihi Learning App

**Khotwa** is an Arabic-first learning and exam-preparation app for Palestinian Tawjihi students. It brings lessons, practice questions, worked solutions, revision paths, and progress tracking into one focused study experience.

## Live site

[Open Khotwa](https://malikahed.github.io/tawjihi-learning-app/)

## Highlights

- Arabic-first interface designed for Tawjihi learners
- Structured learning paths for core subjects
- Practice questions, worked solutions, and exam preparation
- Progress tracking for lessons and review activities
- Responsive layout for phones, tablets, and desktop
- Installable as a progressive web app

## Run locally

```bash
npm install
npm run dev
```

Then open the local address shown by the development server.

## Checks

```bash
npm run check:syntax
npm test
npm run build
```
