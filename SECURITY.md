# Security policy

This repository is private and under active development.

Do not open a public issue for a security or privacy vulnerability. Report it privately to the repository owner through GitHub or another previously agreed private channel.

Never include passwords, session tokens, API credentials, private student information, contact details, or payment evidence in an issue, pull request, screenshot, log, fixture, or commit.

Local SQLite files under `data/` are development data and must not be committed.
