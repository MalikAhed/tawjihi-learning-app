# Map sources

## Gaza Strip

`gaza-map.svg` is adapted and visually simplified from the Gaza Strip `PS02` polygon in the
**State of Palestine Subnational Administrative Boundaries** dataset (ADM1), dated 2021-08-06.
The dataset is an OCHA Common Operational Dataset vetted and served by ITOS.

- Dataset overview: https://www.arcgis.com/home/item.html?id=e8f0b12d965740cbb09bb695effcca4e
- Feature service: https://services7.arcgis.com/JTAZ3WwabnbqJhaC/arcgis/rest/services/State_of_Palestine_Subnational_Administrative_Boundaries/FeatureServer/3
