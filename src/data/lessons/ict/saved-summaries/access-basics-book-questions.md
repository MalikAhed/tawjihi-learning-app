# أسئلة ملخص Access المحفوظة

<!-- Original questions, retained for reuse; not the video practice. -->

:::mcq
id: dbms-task-check
title: وظيفة نظام إدارة قواعد البيانات
question: غيّر الموظف رقم هاتف طالب محفوظ مسبقًا. ما العملية التي قام بها؟
- [ ] insert | إدخال سجل جديد
- [x] update | تحديث بيانات موجودة
- [ ] report | طباعة تقرير
explanation: بيانات الطالب موجودة أصلًا، والذي تغيّر هو قيمة داخل سجله؛ لذلك هذه عملية تحديث.
hint: اسأل نفسك: هل أضاف طالبًا جديدًا، أم غيّر معلومة لطالب موجود؟
:::

:::mcq
id: access-characteristics
title: معنى قاعدة بيانات علائقية
question: ماذا يعني أن Access يدير قاعدة بيانات علائقية؟
- [x] related-tables | البيانات في جداول تربط بينها علاقات منطقية
- [ ] one-page | جميع البيانات يجب أن تكون في جدول واحد فقط
- [ ] no-structure | البيانات تُحفظ بلا حقول أو سجلات
explanation: القاعدة العلائقية تنظّم البيانات في جداول منفصلة، ثم تربط الجداول بعلاقات منطقية.
hint: ركّز على كلمة «علائقية».
:::

:::mcq
id: access-tradeoff-check
title: ملف Access الواحد
question: أصبح ملف قاعدة Access الوحيد غير قابل للاسترجاع، ولا توجد نسخة احتياطية. ما الخطر على محتوياته؟
- [ ] printing | فقدان إمكانية طباعة التقارير فقط
- [x] single-file | فقدان قاعدة البيانات جميعها
- [ ] table-limit | فقدان جدول واحد فقط
explanation: في الحالة المحددة لا يوجد ملف صالح أو نسخة بديلة؛ لذلك نفقد كل مكونات القاعدة المخزنة فيه. أما وجود نسخة احتياطية فقد يتيح الاسترجاع.
hint: فكّر فيما يحدث للجداول والنماذج والتقارير إذا فُقد الملف.
:::

:::mcq
id: access-components
title: مكان تخزين البيانات
question: أي مكوّن يخزّن بيانات الطلبة فعلًا؟
- [x] tables | الجداول
- [ ] forms | النماذج
- [ ] reports | التقارير
explanation: الجداول هي مكان التخزين، بينما النماذج واجهة إدخال والتقارير طريقة عرض وطباعة.
hint: استخدم القاعدة: الجدول يخزّن.
:::

:::mcq
id: component-purpose-check
title: اختيار المكوّن المناسب
question: يريد موظف الاستقبال شاشة سهلة لإضافة طالب جديد دون فتح الجدول مباشرة. ماذا يستخدم؟
- [ ] query | استعلامًا
- [x] form | نموذجًا
- [ ] report | تقريرًا
explanation: النموذج هو الواجهة المخصّصة لإدخال بيانات الجداول وتعديلها وحذفها بسهولة.
hint: ابحث عن المكوّن الذي يعمل كواجهة للمستخدم.
:::

:::mcq
id: access-software-examples-check
title: أمثلة برامج إدارة قواعد البيانات
question: أي مجموعة تتكوّن كلها من برامج إدارة قواعد البيانات المذكورة في الكتاب؟
- [x] database-programs | Microsoft Access، SQL Server، Oracle، MySQL
- [ ] office-programs | Microsoft Access، Word، PowerPoint، Excel
- [ ] language-mix | SQL، Word، Oracle، PowerPoint
explanation: يذكر الكتاب Microsoft Access وSQL Server وOracle وMySQL. أما SQL فهي لغة الاستعلامات البنيوية.
hint: ميّز اسم البرنامج SQL Server عن اسم اللغة SQL.
:::

:::mcq
id: access-shared-language-check
title: اللغة المشتركة
question: ما اللغة التي تتشارك بها برامج إدارة قواعد البيانات المذكورة في الكتاب؟
- [ ] html | HTML
- [x] sql | لغة الاستعلامات البنيوية SQL
- [ ] sql-server | SQL Server
explanation: SQL هي لغة الاستعلامات البنيوية؛ SQL Server اسم برنامج، وليس اسم اللغة.
hint: المطلوب لغة، لا برنامجًا لإدارة القاعدة.
:::

:::mcq
id: access-license-check
title: الترخيص بحسب الكتاب
question: أي برنامج يذكره الكتاب مثالًا على برامج قواعد البيانات المجانية للاستخدام؟
- [ ] access | Microsoft Access
- [ ] oracle | Oracle
- [x] mysql | MySQL
explanation: المثال المقصود في الكتاب هو MySQL. نسخته المجتمعية مجانية تحت ترخيص GPL؛ لذلك نميز مجانية الاستعمال عن غياب الترخيص.
hint: استرجع المثال المجاني المذكور في فقرة برامج إدارة قواعد البيانات.
:::

:::mcq
id: access-choice-check
title: سبب اختيار Access
question: لماذا يستخدم الكتاب برنامج Microsoft Access؟
- [ ] only-program | لأنه البرنامج الوحيد الذي يستخدم SQL
- [x] easy-available | لسهولته وتوافره على معظم أجهزة الحاسوب الشخصية
- [ ] unlimited | لأن حجم ملفه غير محدود
explanation: اختير Access لسهولته وتوافره، وليس لأنه البرنامج الوحيد الذي يستخدم SQL أو لأن حجم ملفه غير محدود.
hint: احفظ السببين معًا: السهولة والتوافر.
:::

:::mcq
id: access-office-check
title: الحزمة التي تضم Access
question: إلى أي حزمة ينتمي Microsoft Access؟
- [x] office | Microsoft Office
- [ ] adobe | Adobe Creative Cloud
- [ ] sql | SQL
explanation: Access أحد برامج Microsoft Office، كما يوضح الكتاب في مقدمة الدرس.
hint: الحزمة تضم برامج مكتبية سبق أن تعاملت معها.
:::

:::mcq
id: access-file-facts-check
title: امتداد الملف وحجمه
question: ما امتداد ملف قاعدة بيانات Access والحد الأقصى لحجمه بحسب الكتاب؟
- [ ] wrong-size | .accdb وحجمه الأقصى 2 MB
- [ ] wrong-extension | .xlsx وحجمه الأقصى 2 GB
- [x] correct-file | .accdb وحجمه الأقصى 2 GB
explanation: يجمع Access مكونات القاعدة في ملف واحد بامتداد .accdb، وحده الأقصى 2 GB وليس 2 MB.
hint: انتبه إلى الامتداد ووحدة قياس الحجم معًا.
:::

:::mcq
id: access-exchange-check
title: استيراد البيانات وتصديرها
question: مع أي برامج يمكن لـ Access تبادل أنواع مختلفة من البيانات بحسب الكتاب؟
- [x] databases-spreadsheets | قواعد بيانات وبرامج جداول إلكترونية أخرى
- [ ] access-only | ملفات Access فقط
- [ ] printing-only | برامج طباعة التقارير فقط
explanation: تشمل الخاصية الاستيراد والتصدير مع قواعد بيانات وبرامج جداول إلكترونية أخرى، ولا تقتصر على Access.
hint: تذكّر نوعي البرامج المذكورين في خاصية الاستيراد والتصدير.
:::

:::mcq
id: access-security-check
title: درجات الأمان
question: ماذا تعني تعدد درجات الأمان في Access بحسب الكتاب؟
- [ ] equal-access | إعطاء جميع المستخدمين الحقوق نفسها دائمًا
- [x] need-based | إعطاء كل مستخدم حقوق الوصول إلى المعلومات حسب حاجته
- [ ] no-access | منع جميع المستخدمين من الوصول إلى القاعدة
explanation: ترتبط حقوق الوصول بحاجة كل مستخدم، ولا يلزم أن تكون متساوية للجميع.
hint: ركّز على عبارة «حسب الحاجة».
:::

:::mcq
id: access-network-check
title: المشاركة عبر الشبكة
question: ماذا تتيح خاصية وضع قاعدة بيانات Access على شبكة حاسوب؟
- [ ] one-user | وصول مستخدم واحد فقط في كل مرة
- [ ] no-edit | عرض التقارير دون الوصول إلى البيانات
- [x] simultaneous | وصول عدة مستخدمين إليها في آن واحد
explanation: يذكر الكتاب أن وضع القاعدة على الشبكة يتيح لعدة مستخدمين الوصول إليها في الوقت نفسه.
hint: انتبه إلى الفرق بين بالتتابع وفي آن واحد.
:::

:::mcq
id: access-admin-check
title: صلاحيات مدير قاعدة البيانات
question: أي وصف يطابق دور مدير قاعدة البيانات بحسب قائمة خصائص Access في الكتاب؟
- [x] permissions | التحكم الكامل بالقاعدة وإعطاء الصلاحيات ومنع التغيير غير المصرح به
- [ ] reports-only | طباعة التقارير دون التحكم بالصلاحيات
- [ ] open-edits | السماح لأي مستخدم بإجراء أي تغيير
explanation: يملك مدير القاعدة خصائص وطرقًا للتحكم بها وإعطاء الصلاحيات ومنع التغيير غير المصرح به.
hint: ميّز بين حقوق المستخدم وأدوات المدير لإدارة تلك الحقوق.
:::

:::mcq
id: access-table-structure-check
title: الحقول والسجلات
question: ممّ يتكوّن الجدول؟
- [ ] reversed | حقول تمثل الصفوف وسجلات تمثل الأعمدة
- [x] fields-records | حقول تمثل الأعمدة وسجلات تمثل الصفوف
- [ ] reports-forms | تقارير ونماذج فقط
explanation: الحقل عمود، والسجل صف. هذه المعلومة واردة في تعريف الجداول في صفحة 4.
hint: اسم الطالب حقل، وبيانات طالب واحد سجل.
:::

:::mcq
id: access-query-operations-check
title: الاستعلام ليس للبحث فقط
question: أي وصف يبيّن وظائف الاستعلامات كاملةً كما يذكرها الكتاب؟
- [ ] search-only | البحث عن البيانات فقط دون تغييرها
- [ ] reports-only | عرض البيانات وطباعتها بتنسيقات مختلفة فقط
- [x] retrieve-and-act | استرجاع بيانات بمعايير محددة وتنفيذ عمليات على السجلات والحقول وإنشاء الجداول وحذفها
explanation: الاستعلامات تسترجع بيانات تحقق معايير، ويمكن أن تنفذ حذفًا وإضافة وتعديلًا لسجلات أو حقول، وإنشاء جداول وحذفها.
hint: التعريف يذكر طلب استرجاع أو أوامر لتنفيذ عمليات.
:::

:::mcq
id: access-form-delete-check
title: وظائف النماذج
question: أي مجموعة تصف العمليات التي تتيحها النماذج على بيانات الجداول؟
- [ ] add-only | الإضافة فقط
- [x] add-edit-delete | الإضافة والتعديل والحذف
- [ ] print-only | العرض والطباعة فقط
explanation: النماذج واجهات لإضافة بيانات الجداول وتعديلها وحذفها. حذف البيانات جزء من تعريفها أيضًا.
hint: لا تختصر وظيفة النموذج في إدخال بيانات جديدة.
:::

:::mcq
id: access-report-display-check
title: وظائف التقارير
question: ما وظيفة التقارير؟
- [x] display-print | عرض البيانات وطباعتها بأشكال وتنسيقات متنوعة
- [ ] store | تخزين البيانات في حقول وسجلات
- [ ] modify | إضافة بيانات الجداول وتعديلها وحذفها
explanation: التقارير وسيلة للعرض والطباعة بأشكال وتنسيقات متنوعة؛ التخزين وظيفة الجداول، وواجهة الإضافة والتعديل والحذف هي النماذج.
hint: تذكّر الفعلين: تعرض وتطبع.
:::

:::mcq
id: access-entity-check
title: الكيان والجدول
question: ما المقصود بالكيان في عبارة الكتاب «الجداول (الكيانات)»؟
- [x] table | الجدول
- [ ] field | الحقل
- [ ] record | السجل
explanation: يستخدم الكتاب الكيانات للإشارة إلى الجداول؛ أما الحقل فهو عمود والسجل صف.
hint: تذكّر الرسم الذي يلوّن الجدول كاملًا.
:::

:::mcq
id: access-other-components-check
title: مكونات Access
question: هل الجداول والاستعلامات والنماذج والتقارير هي جميع مكونات Access؟
- [ ] only-four | نعم، لا توجد مكونات أخرى
- [x] more-components | لا، توجد مكونات أخرى لم يذكرها الكتاب
- [ ] tables-only | الجداول وحدها هي مكونات Access
explanation: يعرض الكتاب أربعة مكونات ثم يوضح أن هناك مكونات أخرى لا داعي لذكرها.
hint: ميّز بين المكونات المذكورة وجميع المكونات.
:::
